   
   
1. **PoetryDB **— easiest API baseline. It provides public-domain/classic poems in JSON, searchable by author, title, lines, and line count. No API key is normally required.  
2. **Gutendex **/  **Project Gutenberg metadata API** — better if you want a larger, more bibliographic corpus and want to filter by subject/bookshelf. Gutendex exposes Project Gutenberg book metadata and search endpoints.  
3. **Gutenberg Poetry Corpus** — best if you want a ready-made poetry corpus rather than an API. The Hugging Face version has about 3,085,117 lines from 1,191 Gutenberg IDs.
