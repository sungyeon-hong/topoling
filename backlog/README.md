# backlog

Working records for topoling, kept so that what a session learns survives the
session.

- **`tasks/`** — one file per task, `task-N - Short-slug.md`. Each carries a
  status (`To Do`, `In Progress`, `Done`) in its frontmatter, what the task is,
  why it matters, and what would count as finishing it.
- **`docs/`** — findings. One file per topic, written to be readable months
  later by someone who was not in the session that produced it.

Start a session by reading `docs/glossary.md` and any task marked
`In Progress`, then the `To Do` tasks in number order.

The status vocabulary matches the `panic-tda` project so the two read alike,
but these files are plain markdown: no tool generates or parses them.
